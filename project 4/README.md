# Modern Jazz Institute - In The Shed

A real-time interactive jazz education platform featuring AI-powered music instruction and live streaming capabilities.

## Features

- Live AI instructor streaming
- Real-time chat interaction
- Music library management
- Performance analytics
- Personalized learning sessions

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- Lucide Icons
- Vite

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/modern-jazz-institute.git
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`
